1. 真空を打ち込んだときはマルチモードのsq. vac.ができる．
2. 単一光子の波束を打ち込んだとき平均光子数がミラーの取り去り時間$T$に対して，$1/T^2$でスケールする（無限小の時間幅で取り去ったら光子数が発散する）
3. 取り去る前と取り去った後の光子の物理量に対する期待値は，局所的な量であればそれぞれ真空と単一光子状態と区別がつかない．

難しく書いたが3つ目以外はまあそんな感じかという印象．結局取り去るときの光子の波束が連続だが微分不可能な形になるせいで，Fourier変換のGibbs現象みたいなことが起きているだけな気がしている．さて，どうやってまとめようか．
